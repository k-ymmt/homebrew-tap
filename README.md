# homebrew-tap

Personal Homebrew tap for [k-ymmt](https://github.com/k-ymmt)'s tools.

## Usage

```sh
brew install --cask k-ymmt/tap/gital
brew install k-ymmt/tap/apvt
```

## Casks

- [Gital](https://github.com/k-ymmt/Gital) — Native macOS Git client built with SwiftUI (macOS 26+)

## Formulae

- [apvt](https://github.com/k-ymmt/apvt) — Shows an AI agent what an iOS Simulator app's views look like (macOS 15+, needs Xcode)
